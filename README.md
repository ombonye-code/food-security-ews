# \# Kenya Food Security Early-Warning System

# 

# A cloud-based data science platform that forecasts staple food prices in Kenya

# (maize, beans, rice) and flags counties at risk of price spikes.

# 

# \*\*Status:\*\* Phase 0, project setup.

# 

# \## Objective

# To design, build and deploy an early-warning system that forecasts staple food

# prices and flags counties at risk of price spikes, using open data.

# 

# \## Planned stack

# Python, pandas, scikit-learn, XGBoost, SHAP, FastAPI, Docker, Azure, Power BI.
